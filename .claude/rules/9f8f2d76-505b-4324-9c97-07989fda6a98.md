<rule_activation id="9f8f2d76-505b-4324-9c97-07989fda6a98" title="Adopt Co-located __tests__ Directories for Core Library Unit Tests: Test File Names" applies_to="packages/core/**">
These rules are ALWAYS ACTIVE for all unit tests within the packages/core library. Test files must be organized in co-located __tests__ directories with clear naming conventions that indicate the module under test.
</rule_activation>

### Rules

- **R-COLOCATED-001** MUST: Test file names MUST clearly indicate the module under test (e.g., move-component.spec.tsx tests move-component functionality).
- **R-COLOCATED-002** MUST: All .spec.tsx test files in packages/core MUST be located within __tests__ directories co-located with their source code.
- **R-COLOCATED-003** MUST: Test files MUST use the .spec.tsx naming convention for TypeScript React test files.
- **R-COLOCATED-004** MUST: Build configuration MUST explicitly exclude __tests__ directories and .spec.tsx files from production bundles.
- **R-COLOCATED-005** MUST: Jest or test runner configuration MUST include __tests__ in test discovery patterns.
- **R-COLOCATED-006** SHOULD: Shared test helpers SHOULD be organized in __helpers__ subdirectories within __tests__ and exported via an index file.
- **R-COLOCATED-007** SHOULD: When moving or renaming source files, corresponding test files SHOULD be moved to maintain co-location.
- **R-COLOCATED-008** MAY: Legacy test files that exist in a different structure MAY be exempted if refactoring would introduce significant risk (EX-001).
- **R-COLOCATED-009** MAY: Cross-cutting integration tests MAY be exempted if they require access to multiple package internals (EX-002).

### Verify

```bash
# Verify no .spec.tsx files exist outside __tests__ directories
find packages/core -name '*.spec.tsx' -not -path '*/__tests__/*' | wc -l | grep -q '^0$'

# Verify Jest configuration includes __tests__ in test discovery
grep -r "testMatch" jest.config.* | grep -q "__tests__"

# Verify baseline of co-located test files exists
find packages/core/__tests__ -name '*.spec.tsx' | wc -l

# Verify build configuration excludes test files
grep -r "exclude" tsconfig.json | grep -q "__tests__"
```

**Accept when:**
- All .spec.tsx test files in packages/core are located within __tests__ directories
- Jest or test runner configuration includes __tests__ in test discovery patterns (testMatch: ['**/__tests__/**/*.spec.tsx'])
- Build configuration explicitly excludes __tests__ directories and .spec.tsx files from production bundles
- At least 10 test files follow the co-located __tests__ pattern (current baseline)
- No .spec.tsx files are found outside __tests__ directories in packages/core
- TypeScript configuration excludes test files from production builds

<enforcement>
Claude Code MUST NOT skip or defer verification. All verify commands MUST pass before accepting code changes that affect test organization or naming in packages/core. Violations MUST trigger CI pipeline failures and block pull requests until tests are moved to correct locations.
</enforcement>
