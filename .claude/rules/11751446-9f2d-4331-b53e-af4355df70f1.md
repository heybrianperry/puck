<rule_activation id="11751446-9f2d-4331-b53e-af4355df70f1" title="Adopt Console-Based Logging for Development and Debugging: Error Conditions Exceptional" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching `**/*`. Console-based logging is the standard approach for development and debugging across client-side and server-side code without introducing heavy logging dependencies.
</rule_activation>

### Rules

- **R-LOG-001** MUST: Error conditions and exceptional states MUST be logged using console.error with descriptive context.
- **R-LOG-002** SHOULD: Prefer console.warn for warnings and console.log for informational messages to leverage browser DevTools filtering.
- **R-LOG-003** SHOULD: Use descriptive log messages with sufficient context (function name, relevant variables, operation being performed) to aid debugging.
- **R-LOG-004** SHOULD: Consider using environment checks (e.g., if (process.env.NODE_ENV === 'development')) to conditionally enable verbose logging.
- **R-LOG-005** MUST NOT: Introduce logging framework dependencies (winston, pino, bunyan, log4js) to core library code (packages/core/*).
- **R-LOG-006** MUST NOT: Log sensitive data (PII, credentials, tokens) to console output.

### Verify

```bash
# Count console usage in core libraries
grep -r 'console\.(log|warn|error|info|debug)' packages/core/ --include='*.ts' --include='*.tsx' | wc -l

# Verify no logging framework imports in core
! grep -r 'import.*winston\|import.*pino\|import.*bunyan' packages/core/ --include='*.ts' --include='*.tsx'

# Verify no logging framework dependencies
npm list --depth=0 | grep -E 'winston|pino|bunyan|log4js' && exit 1 || exit 0
```

**Accept when:**
- Core library code uses console methods for logging without third-party logging dependencies
- No logging frameworks (winston, pino, bunyan, log4js) are listed as dependencies in core package.json
- Console usage is detectable via grep across identified pattern files with consistent usage patterns
- Error conditions use console.error with descriptive context
- No sensitive data (PII, credentials, tokens) appears in log statements

<enforcement>
Claude Code MUST verify all rules before approving changes to core library code. Violations of R-LOG-001, R-LOG-005, and R-LOG-006 require architecture and/or security team review before merge. Verification is mandatory and cannot be deferred.
</enforcement>
