<rule_activation id="f93ef6e7-2450-414a-a2d6-30ec1188026f" title="Adopt Console-Based Logging for Development and Debugging: Core Libraries Not" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching `**/*`. Core libraries MUST NOT introduce third-party logging frameworks as required dependencies. Console-based logging is the standard approach for development and debugging across client-side and server-side code.
</rule_activation>

### Rules

- **R-CONSOLE-001** MUST_NOT: Core libraries MUST NOT introduce third-party logging frameworks (winston, pino, bunyan, log4js) as required dependencies.
- **R-CONSOLE-002** MUST: Use console methods (console.log, console.warn, console.error, console.info, console.debug) for logging in core library code.
- **R-CONSOLE-003** SHOULD: Use console.error for error conditions, console.warn for warnings, and console.log for informational messages to leverage browser DevTools filtering.
- **R-CONSOLE-004** SHOULD: Include descriptive log messages with sufficient context (function name, relevant variables, operation being performed) to aid debugging.
- **R-CONSOLE-005** MAY: Use environment checks (e.g., if (process.env.NODE_ENV === 'development')) to conditionally enable verbose logging.
- **R-CONSOLE-006** SHOULD: Document logging behavior in libraries and provide guidance on how consuming applications can suppress or redirect console output if needed.
- **R-CONSOLE-007** MUST: Avoid logging sensitive data (PII, credentials, tokens) to console in production environments.

### Verify

```bash
# Count console usage in core libraries
grep -r 'console\.(log|warn|error|info|debug)' packages/core/ --include='*.ts' --include='*.tsx' | wc -l

# Verify no logging frameworks are imported
! grep -r 'import.*winston\|import.*pino\|import.*bunyan' packages/core/ --include='*.ts' --include='*.tsx'

# Verify no logging frameworks in dependencies
npm list --depth=0 | grep -E 'winston|pino|bunyan|log4js' && exit 1 || exit 0
```

**Accept when:**
- Core library code uses console methods for logging without third-party logging dependencies
- No logging frameworks (winston, pino, bunyan, log4js) are listed as dependencies in core package.json
- Console usage is detectable via grep across core library files with consistent usage patterns
- No sensitive data (PII, credentials, tokens) is present in log statements
- Log messages include sufficient context for debugging purposes

<enforcement>
Claude Code MUST verify all rules via the bash commands above before approving changes to core library logging. Violations must be flagged for architecture review. Code review must include a checklist item to verify console usage patterns and check for sensitive data in log statements.
</enforcement>
