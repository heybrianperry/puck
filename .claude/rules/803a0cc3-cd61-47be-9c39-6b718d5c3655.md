<rule_activation id="803a0cc3-cd61-47be-9c39-6b718d5c3655" title="Adopt Snapshot Testing for Component and Reducer Unit Tests: Snapshot Test Files" applies_to="**/*.spec.ts,**/*.spec.tsx">
These rules are ALWAYS ACTIVE for all snapshot test files matching `**/*.spec.ts` and `**/*.spec.tsx` in packages/core/lib and packages/core/reducer directories.
</rule_activation>

### Rules

- **R-SNAPSHOT-001** MUST: Snapshot test files MUST use the .spec.ts or .spec.tsx extension to ensure CI/CD pipeline recognition.
- **R-SNAPSHOT-002** MUST: Use Jest's toMatchSnapshot() or toMatchInlineSnapshot() methods for snapshot assertions in test files.
- **R-SNAPSHOT-003** MUST: Organize snapshot files in __snapshots__ directories adjacent to test files, following Jest conventions.
- **R-SNAPSHOT-004** SHOULD: Configure snapshot serializers for common data types (React elements, dates, etc.) to improve snapshot readability.
- **R-SNAPSHOT-005** SHOULD: Include snapshot review guidelines in team documentation and code review checklists.
- **R-SNAPSHOT-006** SHOULD: Set up CI pipeline to fail on uncommitted snapshot changes to prevent accidental omissions.
- **R-SNAPSHOT-007** MAY: Use hybrid approach with snapshots for structure and targeted assertions for critical values (per rule R-50-007).

### Verify

```bash
# Verify snapshot assertions are present in test files
grep -r 'toMatchSnapshot\|toMatchInlineSnapshot' packages/core/lib/data/__tests__/ packages/core/reducer/actions/__tests__/

# Count snapshot directories
find packages/core -type d -name '__snapshots__' | wc -l

# Run snapshot tests with coverage
npm test -- --coverage --testPathPattern='spec\.(ts|tsx)$'

# Verify all .spec.ts and .spec.tsx files exist in expected locations
find packages/core/lib/data/__tests__/ packages/core/reducer/actions/__tests__/ -name '*.spec.ts' -o -name '*.spec.tsx'
```

**Accept when:**
- All .spec.ts and .spec.tsx files in packages/core/lib/data/__tests__/ and packages/core/reducer/actions/__tests__/ contain at least one snapshot assertion
- Snapshot directories exist alongside test files and contain .snap files for each test suite
- CI pipeline successfully runs snapshot tests and fails on snapshot mismatches
- No uncommitted snapshot changes are present in the working directory
- Code review process includes mandatory review of snapshot diffs before merge

<enforcement>
Claude Code MUST NOT skip or defer verification of snapshot testing adoption. All snapshot test files MUST conform to the .spec.ts/.spec.tsx naming convention and use Jest snapshot methods. Violations block pull request merge until resolved.
</enforcement>
