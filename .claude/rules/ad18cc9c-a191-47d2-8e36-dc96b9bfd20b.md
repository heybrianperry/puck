<rule_activation id="ad18cc9c-a191-47d2-8e36-dc96b9bfd20b" title="Adopt Co-located __tests__ Directories for Core Library Unit Tests: Integration Tests That" applies_to="packages/core/**/*">
These rules are ALWAYS ACTIVE for all test files and source code in the packages/core library.
</rule_activation>

### Rules

- **R-COLOCATED-001** MUST: All unit tests within packages/core library MUST be organized in __tests__ directories co-located with the source code they test.
- **R-COLOCATED-002** MUST: TypeScript React test files MUST use the .spec.tsx naming convention.
- **R-COLOCATED-003** MAY: Integration tests that span multiple modules MAY be organized in a dedicated __tests__/integration directory at the package root.
- **R-COLOCATED-004** MUST: Test files MUST NOT be placed directly alongside source files in the same directory.
- **R-COLOCATED-005** MUST: Production code MUST NOT import from __tests__ directories.
- **R-COLOCATED-006** SHOULD: Shared test helpers SHOULD be organized in __helpers__ subdirectories within __tests__.

### Verify

```bash
# Verify no .spec.tsx files exist outside __tests__ directories
find packages/core -name '*.spec.tsx' -not -path '*/__tests__/*' | wc -l | grep -q '^0$'

# Verify Jest configuration includes __tests__ in test discovery
grep -r "testMatch" jest.config.* | grep -q "__tests__"

# Count co-located test files to maintain baseline
find packages/core/__tests__ -name '*.spec.tsx' | wc -l

# Verify no production imports from __tests__ directories
grep -r "from.*__tests__" packages/core --include="*.ts" --include="*.tsx" --exclude-dir=__tests__ | wc -l | grep -q '^0$'

# Verify build configuration excludes test files
grep -r "exclude" tsconfig.json | grep -q "__tests__"
```

**Accept when:**
- All .spec.tsx test files in packages/core are located within __tests__ directories
- Jest or test runner configuration includes __tests__ in test discovery patterns
- Build configuration explicitly excludes __tests__ directories and .spec.tsx files from production bundles
- At least 10 test files follow the co-located __tests__ pattern (current baseline)
- No production code imports from __tests__ directories
- TypeScript configuration excludes test files from production builds

Claude Code MUST verify all rules before accepting code changes to packages/core. Violations MUST block pull requests until tests are moved to correct locations. Automated CI checks MUST enforce test file locations and naming conventions.
