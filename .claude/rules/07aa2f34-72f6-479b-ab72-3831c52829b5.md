<rule_activation id="07aa2f34-72f6-479b-ab72-3831c52829b5" title="Adopt Co-located __tests__ Directories for Core Library Unit Tests: Test Files Typescript" applies_to="packages/core/**">
These rules are ALWAYS ACTIVE for all test files in the packages/core library. Test files for TypeScript React components and utilities must follow co-located __tests__ directory conventions with .spec.tsx naming.
</rule_activation>

### Rules

- **R-COLOCATED-001** MUST: Test files for TypeScript React components and utilities MUST use the .spec.tsx file extension.
- **R-COLOCATED-002** MUST: All unit tests within the packages/core library MUST be organized in __tests__ directories co-located with their source code.
- **R-COLOCATED-003** MUST: Test files MUST NOT be placed directly alongside source files in the same directory.
- **R-COLOCATED-004** SHOULD: Shared test helpers SHOULD be organized in __helpers__ subdirectories within __tests__ and exported via an index file.
- **R-COLOCATED-005** MUST: Production code MUST NOT import from __tests__ directories.

### Verify

```bash
# Verify no .spec.tsx files exist outside __tests__ directories
find packages/core -name '*.spec.tsx' -not -path '*/__tests__/*' | wc -l | grep -q '^0$'

# Verify Jest configuration includes __tests__ in test discovery
grep -r "testMatch" jest.config.* | grep -q "__tests__"

# Verify baseline of co-located test files
find packages/core/__tests__ -name '*.spec.tsx' | wc -l

# Verify TypeScript excludes test files from production builds
grep -q "exclude.*__tests__" tsconfig.json
grep -q "exclude.*\.spec\.tsx" tsconfig.json

# Verify build configuration excludes test patterns
grep -r "exclude.*__tests__" webpack.config.* || grep -r "exclude.*__tests__" build.config.*
```

**Accept when:**
- All .spec.tsx test files in packages/core are located within __tests__ directories
- Jest or test runner configuration includes __tests__ in test discovery patterns (testMatch: ['**/__tests__/**/*.spec.tsx'])
- Build configuration explicitly excludes __tests__ directories and .spec.tsx files from production bundles
- TypeScript configuration excludes test files from production builds
- At least 10 test files follow the co-located __tests__ pattern (current baseline)
- No production code imports from __tests__ directories

<enforcement>
Claude Code MUST verify all rules before accepting test file organization. Verification is mandatory and MUST NOT be skipped or deferred. All .spec.tsx files MUST be co-located in __tests__ directories.
</enforcement>
