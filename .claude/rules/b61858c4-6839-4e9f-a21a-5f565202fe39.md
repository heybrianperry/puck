### Rules

- **R-JEST-001** MUST: All test files MUST use the .spec.tsx or .spec.ts extension for TypeScript test files
- **R-JEST-002** MUST: Test files MUST be organized in __tests__ directories co-located with source code
- **R-JEST-003** MUST: React component tests MUST use @testing-library/react for rendering and queries
- **R-JEST-004** MUST: Jest MUST be configured as the test runner with TypeScript support
- **R-JEST-005** SHOULD: Create shared test helpers and fixtures in __helpers__ directories to promote reusability
- **R-JEST-006** SHOULD: Use snapshots sparingly and only for stable serialized output; prefer explicit assertions for critical behavior
- **R-JEST-007** SHOULD: Balance unit tests with integration tests that use minimal mocking

### Verify

```bash
# Count test files with proper naming convention
grep -r "describe\|it\|test" packages/core/**/__tests__/**/*.spec.tsx | wc -l

# Verify __tests__ directory structure exists
find packages/core -type d -name '__tests__' | wc -l

# Verify React Testing Library is imported in tests
grep -r "@testing-library/react" packages/core/**/__tests__/**/*.spec.tsx | wc -l

# List all test files matching convention
npm test -- --listTests | grep -E '\.spec\.(tsx|ts)$' | wc -l

# Run full test suite
npm test

# Check Jest configuration exists
test -f jest.config.js && echo "Jest config found"

# Verify coverage thresholds are met
npm test -- --coverage
```

**Accept when:**
- All test files use .spec.tsx or .spec.ts extensions and are located in __tests__ directories
- Jest is configured as the test runner and all tests execute successfully with 'npm test'
- React component tests import and use @testing-library/react for rendering and queries
- Test coverage reports are generated successfully and meet minimum threshold requirements
- ESLint rules enforce testing-library best practices via eslint-plugin-testing-library
- Pre-commit hooks successfully run tests for changed files
