<rule_activation id="a59a6b8f-6b49-40dc-a1e5-4e4aaa77a4de" title="Adopt Console-Based Logging for Development and Debugging: Development Debugging Logs" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching `**/*`. Console-based logging is the standard for development and debugging across core libraries, React components, hooks, and server-side entry points.
</rule_activation>

### Rules

- **R-LOG-001** SHOULD: Development and debugging logs SHOULD use console.log for informational output that aids troubleshooting.
- **R-LOG-002** SHOULD: Prefer console.error for error conditions to leverage browser DevTools filtering.
- **R-LOG-003** SHOULD: Prefer console.warn for warnings to leverage browser DevTools filtering.
- **R-LOG-004** SHOULD: Use descriptive log messages with sufficient context (function name, relevant variables, operation being performed) to aid debugging.
- **R-LOG-005** MAY: Consider using environment checks (e.g., if (process.env.NODE_ENV === 'development')) to conditionally enable verbose logging.
- **R-LOG-006** MUST NOT: Introduce logging framework dependencies (winston, pino, bunyan, log4js) to core library code.
- **R-LOG-007** MUST NOT: Log sensitive data (PII, credentials, tokens) to console without careful review.

### Verify

```bash
# Count console usage in core libraries
grep -r 'console\.(log|warn|error|info|debug)' packages/core/ --include='*.ts' --include='*.tsx' | wc -l

# Verify no logging framework imports in core
! grep -r 'import.*winston\|import.*pino\|import.*bunyan' packages/core/ --include='*.ts' --include='*.tsx'

# Verify no logging framework dependencies
npm list --depth=0 | grep -E 'winston|pino|bunyan|log4js' && exit 1 || exit 0
```

**Accept when:**
- Core library code uses console methods for logging without third-party logging dependencies
- No logging frameworks (winston, pino, bunyan, log4js) are listed as dependencies in core package.json
- Console usage is detectable via grep across identified pattern files with consistent usage patterns
- Log statements do not contain obvious sensitive data (PII, credentials, tokens)

<enforcement>
Claude Code MUST verify console-based logging compliance via automated dependency scanning and code review before approving changes to core libraries. Violations flagged for architecture review.
</enforcement>
