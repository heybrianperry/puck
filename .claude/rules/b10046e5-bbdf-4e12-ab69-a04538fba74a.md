<rule_activation id="b10046e5-bbdf-4e12-ab69-a04538fba74a" title="Adopt Console-Based Logging for Development and Debugging: Core Library Functions" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching the scope of core library functions, React components and hooks, server-side entry points, and data resolution utilities.
</rule_activation>

### Rules

- **R-CONSOLE-001** MUST: All core library functions MUST use console methods (console.log, console.warn, console.error) for logging and debugging output.
- **R-CONSOLE-002** MUST: Core library code (packages/core/*) MUST NOT introduce logging framework dependencies (winston, pino, bunyan, log4js).
- **R-CONSOLE-003** SHOULD: Use console.error for error conditions, console.warn for warnings, and console.log for informational messages to leverage browser DevTools filtering.
- **R-CONSOLE-004** SHOULD: Include descriptive log messages with sufficient context (function name, relevant variables, operation being performed) to aid debugging.
- **R-CONSOLE-005** MAY: Consider using environment checks (e.g., if (process.env.NODE_ENV === 'development')) to conditionally enable verbose logging.
- **R-CONSOLE-006** MUST: Code review MUST check for sensitive data (PII, credentials, tokens) in log statements before merge.

### Verify

```bash
# Count console method usage in core libraries
grep -r 'console\.(log|warn|error|info|debug)' packages/core/ --include='*.ts' --include='*.tsx' | wc -l

# Verify no logging framework imports in core libraries
! grep -r 'import.*winston\|import.*pino\|import.*bunyan' packages/core/ --include='*.ts' --include='*.tsx'

# Verify no logging framework dependencies in package.json
npm list --depth=0 | grep -E 'winston|pino|bunyan|log4js' && exit 1 || exit 0
```

**Accept when:**
- Core library code uses console methods for logging without third-party logging dependencies
- No logging frameworks (winston, pino, bunyan, log4js) are listed as dependencies in core package.json
- Console usage is detectable via grep across core library files with consistent usage patterns
- Code review confirms no sensitive data (PII, credentials, tokens) is logged to console

<enforcement>
Claude Code MUST NOT skip or defer verification. Violations flagged by automated dependency scanning or code review require architecture team discussion before proceeding.
</enforcement>
