<rule_activation id="ba63266b-e16b-494c-a872-2c82e1f68369" title="Standardize External API Documentation with Embedded Analytics and Metadata: Public Facing Documentation" applies_to="**/*">
These rules are ALWAYS ACTIVE for all public-facing API documentation, demo applications, developer portals, and marketing pages for APIs.
</rule_activation>

### Rules

- **R-PUBDOC-001** MUST: All public-facing API documentation and demo applications MUST include standardized metadata configuration (title, description, favicon, Open Graph tags).
- **R-PUBDOC-002** MUST: No hardcoded API keys, secrets, or tokens are permitted in source code; all credentials MUST use environment variables.
- **R-PUBDOC-003** MUST: All .env files MUST be properly gitignored and not tracked in version control.
- **R-PUBDOC-004** MUST: External service integrations MUST be conditionally loaded based on environment configuration.
- **R-PUBDOC-005** SHOULD: Use framework-specific environment variable patterns (e.g., NEXT_PUBLIC_ prefix for Next.js, VITE_ for Vite) to control client-side exposure.
- **R-PUBDOC-006** SHOULD: Implement a configuration validation layer that checks for required metadata and warns about missing environment variables.
- **R-PUBDOC-007** MAY: Use domain-restricted API keys for client-side integrations where explicitly designed for public use (EXC-001).

### Verify

```bash
# Scan for hardcoded credentials in source files
grep -r "API_KEY\|SECRET\|TOKEN" --include="*.tsx" --include="*.ts" --include="*.jsx" --include="*.js" | grep -v "process.env" | grep -v "import.meta.env"

# Check for unignored .env files
find . -name "*.env" -not -path "*/node_modules/*" -not -path "*/.git/*" | xargs git check-ignore -v

# Verify presence of standard metadata tags
grep -r "<meta.*og:" --include="*.tsx" --include="*.html" | wc -l
```

**Accept when:**
- No hardcoded API keys, secrets, or tokens are found in source code (all use environment variables)
- All .env files are properly gitignored and not tracked in version control
- Public-facing applications include standard metadata tags (Open Graph, Twitter Card, etc.)
- External service integrations are conditionally loaded based on environment configuration
- CI/CD pipeline secret scanning tools (git-secrets, truffleHole) report zero violations

<enforcement>
Claude Code MUST verify all rules before accepting changes to public-facing documentation, demo applications, developer portals, or API marketing pages. Verification is mandatory and MUST NOT be skipped or deferred. CI/CD pipeline MUST fail if secrets are detected in code.
</enforcement>
