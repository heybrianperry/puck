<rule_activation id="265585d5-1e37-4340-9052-4ef31eaa2acc" title="Adopt Jest and React Testing Library for Component Testing: Test Helper Functions" applies_to="**/__tests__/**/*.spec.tsx">
These rules are ALWAYS ACTIVE for all test files in __tests__ directories matching `**/__tests__/**/*.spec.tsx`.
</rule_activation>

### Rules

- **R-JEST-001** SHOULD: Test helper functions and fixtures SHOULD be organized in __helpers__ directories within __tests__ for reusability

### Verify

```bash
# Count test files using describe/it/test patterns
grep -r "describe\|it\|test" packages/core/**/__tests__/**/*.spec.tsx | wc -l

# Count __tests__ directories
find packages/core -type d -name '__tests__' | wc -l

# Verify React Testing Library usage
grep -r "@testing-library/react" packages/core/**/__tests__/**/*.spec.tsx | wc -l

# Count test files with correct extension
npm test -- --listTests | grep -E '\.spec\.(tsx|ts)$' | wc -l
```

**Accept when:**
- All test files use .spec.tsx or .spec.ts extensions and are located in __tests__ directories
- Jest is configured as the test runner and all tests execute successfully with 'npm test'
- React component tests import and use @testing-library/react for rendering and queries
- Test coverage reports are generated successfully and meet minimum threshold requirements
- Test helper functions and fixtures are organized in __helpers__ subdirectories within __tests__

<enforcement>
Claude Code MUST NOT skip or defer verification of test file organization, Jest configuration, and React Testing Library usage. All violations MUST be flagged during code review and pull requests with failing tests MUST be blocked from merging.
</enforcement>
