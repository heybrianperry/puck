<rule_activation id="5eb19df7-b722-4f37-a15d-be8f1144f173" title="Adopt Co-located __tests__ Directories for Core Library Unit Tests: Each Source Module" applies_to="packages/core/**/*">
These rules are ALWAYS ACTIVE for all unit tests within the packages/core library. Each source module SHOULD have a corresponding test file co-located in a __tests__ directory with matching base name and .spec.tsx extension.
</rule_activation>

### Rules

- **R-COLOCATED-001** SHOULD: Each source module SHOULD have a corresponding test file with matching base name (e.g., resolve-data.ts → resolve-data.spec.tsx)
- **R-COLOCATED-002** SHOULD: Test files SHOULD be placed in __tests__ directories co-located with their corresponding source modules
- **R-COLOCATED-003** SHOULD: TypeScript React test files SHOULD use the .spec.tsx naming convention for explicit test file identification
- **R-COLOCATED-004** SHOULD: Shared test helpers SHOULD be organized in __helpers__ subdirectories within __tests__ and exported via index files
- **R-COLOCATED-005** MUST: Production code MUST NOT import from __tests__ directories
- **R-COLOCATED-006** SHOULD: When moving or renaming source files, corresponding test files SHOULD be moved to maintain co-location

### Scope

**In scope:**
- All unit tests within the packages/core library
- Component tests (e.g., Puck component tests)
- Library utility tests (e.g., move-component, migrate, transform-props)
- Data operation tests (e.g., resolve-and-replace-data, resolve-data-by-id)
- Reducer and state management tests
- Test helper utilities and fixtures

**Out of scope:**
- End-to-end tests that test the entire application
- Integration tests that require external services or databases
- Performance and load tests
- Visual regression tests
- Tests in other packages outside packages/core
- Documentation examples that are not formal tests

### Verify

```bash
# Verify no .spec.tsx files exist outside __tests__ directories
find packages/core -name '*.spec.tsx' -not -path '*/__tests__/*' | wc -l | grep -q '^0$'

# Verify Jest configuration includes __tests__ in test discovery
grep -r "testMatch" jest.config.* | grep -q "__tests__"

# Verify baseline: at least 10 test files follow the co-located pattern
find packages/core/__tests__ -name '*.spec.tsx' | wc -l

# Verify build configuration excludes test files
grep -r "exclude" tsconfig.json | grep -q "__tests__"
```

**Accept when:**
- All .spec.tsx test files in packages/core are located within __tests__ directories
- Jest or test runner configuration includes __tests__ in test discovery patterns (testMatch: ['**/__tests__/**/*.spec.tsx'])
- Build configuration explicitly excludes __tests__ directories and .spec.tsx files from production bundles
- TypeScript configuration excludes test files: exclude: ['**/__tests__/**', '**/*.spec.tsx']
- At least 10 test files follow the co-located __tests__ pattern (current baseline)
- No production code imports from __tests__ directories
