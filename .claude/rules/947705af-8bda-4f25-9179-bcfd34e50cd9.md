<rule_activation id="947705af-8bda-4f25-9179-bcfd34e50cd9" title="Implement Console Logging with Conditional Debug Output for Development Observability: Console Logging Statements" applies_to="**/*">
These rules are ALWAYS ACTIVE for all frontend components, React components, and client-side JavaScript/TypeScript code to ensure console logging is conditionally executed and sensitive data is never exposed.
</rule_activation>

### Rules

- **R-CONSOLE-001** MUST: Console logging statements MUST be conditionally executed based on environment variables or build-time flags to prevent execution in production.

### Verify

```bash
# Scan for console statements containing sensitive data patterns
grep -r "console\.log.*token\|console\.log.*password\|console\.log.*secret\|console\.log.*apiKey" --include="*.ts" --include="*.tsx" --include="*.js" --include="*.jsx" .

# Verify production builds have console statements stripped
NODE_ENV=production npm run build && grep -r "console\.log\|console\.warn" dist/ || echo 'No console statements in production build'

# Lint for console usage violations
eslint . --ext .ts,.tsx,.js,.jsx --rule 'no-console: [error, { allow: [warn, error] }]' --env-info
```

**Accept when:**
- No console logging statements contain sensitive data patterns (token, password, secret, apiKey, credentials) as verified by grep scan
- Production builds have all console.log statements removed or disabled as verified by bundle inspection
- ESLint or similar linting tools are configured to warn or error on console usage in production code paths
- All console logging statements are guarded by environment checks (e.g., `process.env.NODE_ENV !== 'production'`)
- Build tools (terser, babel, webpack) are configured with `drop_console: true` for production builds
- Code review checklist confirms new logging statements are conditional and don't contain sensitive data

<enforcement>
Claude Code MUST NOT skip or defer verification. Pre-commit hooks, CI/CD pipeline checks, and code review processes MUST validate compliance with R-CONSOLE-001 before merge approval. Violations block commits and CI builds fail if sensitive data patterns are detected.
</enforcement>
