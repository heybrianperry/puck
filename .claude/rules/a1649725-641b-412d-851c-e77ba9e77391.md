<rule_activation id="a1649725-641b-412d-851c-e77ba9e77391" title="Adopt Co-located __tests__ Directories for Core Library Unit Tests: Unit Tests Packages" applies_to="packages/core/**/*">
These rules are ALWAYS ACTIVE for all unit tests in the packages/core library.
</rule_activation>

### Rules

- **R-COLOCATED-001** MUST: All unit tests for packages/core library modules MUST be placed in a __tests__ directory co-located with the source code under test.

### Verify

```bash
# Verify no .spec.tsx files exist outside __tests__ directories
find packages/core -name '*.spec.tsx' -not -path '*/__tests__/*' | wc -l | grep -q '^0$'

# Verify Jest configuration includes __tests__ in test discovery
grep -r "testMatch" jest.config.* | grep -q "__tests__"

# Count test files following the co-located pattern
find packages/core/__tests__ -name '*.spec.tsx' | wc -l
```

**Accept when:**
- All .spec.tsx test files in packages/core are located within __tests__ directories
- Jest or test runner configuration includes __tests__ in test discovery patterns (testMatch: ['**/__tests__/**/*.spec.tsx'])
- Build configuration explicitly excludes __tests__ directories and .spec.tsx files from production bundles
- TypeScript configuration excludes test files: exclude: ['**/__tests__/**', '**/*.spec.tsx']
- At least 10 test files follow the co-located __tests__ pattern (current baseline)
- No test files are found outside __tests__ directories in packages/core

<enforcement>
Claude Code MUST NOT skip or defer verification. All unit tests in packages/core MUST comply with co-located __tests__ directory structure. CI pipeline MUST fail if test files are found outside __tests__ directories. Pull requests MUST be blocked until tests are moved to correct locations.
</enforcement>
