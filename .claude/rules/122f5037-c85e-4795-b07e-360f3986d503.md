<rule_activation id="122f5037-c85e-4795-b07e-360f3986d503" title="Adopt TypeScript Configuration Export Pattern for Public API Packages: Route Handlers Public" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in public API packages under /packages/*, recipe/example applications demonstrating public API usage, shared configuration packages, plugin packages, and field adapter packages.
</rule_activation>

### Rules

- **R-TSCONFIG-001** MUST: API route handlers and public endpoints MUST follow consistent naming conventions (e.g., api.*.tsx, routes/api/*) to clearly identify external interfaces
- **R-TSCONFIG-002** MUST: All public packages under /packages/* MUST contain either tsup.config.ts or equivalent build configuration
- **R-TSCONFIG-003** MUST: Package.json files for public packages MUST define explicit exports field with type definitions
- **R-TSCONFIG-004** MUST: Use the shared tsup-config package as the foundation for all new public packages to ensure consistency
- **R-TSCONFIG-005** MUST: Define package.json exports field with explicit entry points for main, types, and any conditional exports (import/require)
- **R-TSCONFIG-006** SHOULD: Include both ESM and CJS outputs when necessary for broader compatibility, but prefer ESM as the primary format
- **R-TSCONFIG-007** SHOULD: Document public API surface in README files and consider using API Extractor or similar tools to generate API documentation
- **R-TSCONFIG-008** SHOULD: Leverage TypeScript's declaration maps for better debugging experience in consumer projects

### Verify

```bash
# Count tsup.config.ts files in packages
grep -r "tsup.config.ts" packages/*/tsup.config.ts | wc -l

# Count package.json files with exports field
find packages -name 'package.json' -exec jq -e '.exports' {} \; 2>/dev/null | wc -l

# Count explicit exports in index.ts files
grep -r "export.*from" packages/*/index.ts | grep -v "// internal" | wc -l
```

**Accept when:**
- All public packages under /packages/* contain either tsup.config.ts or equivalent build configuration
- Package.json files for public packages define explicit exports field with type definitions
- API route handlers follow consistent naming conventions (api.* or routes/api/*) across recipe applications
- Shared build configuration (tsup-config) is used by at least 80% of public packages

<enforcement>
Claude Code MUST verify all rules using the provided bash commands before accepting changes to public packages, API route handlers, or build configurations. Violations trigger CI pipeline failures and require architecture review approval for exceptions.
</enforcement>
