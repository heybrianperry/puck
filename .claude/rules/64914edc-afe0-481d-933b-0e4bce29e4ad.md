<rule_activation id="64914edc-afe0-481d-933b-0e4bce29e4ad" title="Adopt Co-located __tests__ Directories for Core Library Unit Tests: Test Helper Utilities" applies_to="packages/core/**">
These rules are ALWAYS ACTIVE for all unit tests and test helpers within the packages/core library.
</rule_activation>

### Rules

- **R-COLOCATED-001** SHOULD: Test helper utilities shared across multiple test files SHOULD be placed in `__helpers__` subdirectories within `__tests__`.
- **R-COLOCATED-002** SHOULD: All unit tests within packages/core library SHOULD be organized in co-located `__tests__` directories adjacent to source code.
- **R-COLOCATED-003** SHOULD: TypeScript React test files SHOULD use the `.spec.tsx` naming convention for explicit test file identification.
- **R-COLOCATED-004** MUST: Test files MUST NOT be placed directly alongside source files in the same directory.
- **R-COLOCATED-005** MUST: Production code MUST NOT import from `__tests__` directories.

### Verify

```bash
# Verify no .spec.tsx files exist outside __tests__ directories
find packages/core -name '*.spec.tsx' -not -path '*/__tests__/*' | wc -l | grep -q '^0$'

# Verify Jest configuration includes __tests__ in test discovery
grep -r "testMatch" jest.config.* | grep -q "__tests__"

# Count test files following the co-located pattern
find packages/core/__tests__ -name '*.spec.tsx' | wc -l

# Verify no production imports from __tests__ directories
grep -r "from.*__tests__" packages/core --include="*.ts" --include="*.tsx" --exclude-dir=__tests__ | wc -l | grep -q '^0$'

# Verify TypeScript build excludes test files
grep -A 5 '"exclude"' tsconfig.json | grep -q '__tests__'
```

**Accept when:**
- All `.spec.tsx` test files in packages/core are located within `__tests__` directories
- Jest or test runner configuration includes `__tests__` in test discovery patterns
- Build configuration explicitly excludes `__tests__` directories and `.spec.tsx` files from production bundles
- At least 10 test files follow the co-located `__tests__` pattern (current baseline)
- No production code imports from `__tests__` directories
- Test helper utilities are organized in `__helpers__` subdirectories within `__tests__`
