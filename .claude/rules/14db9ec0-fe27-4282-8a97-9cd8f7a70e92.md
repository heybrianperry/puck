### Rules

- **R-JEST-001** MUST: Use Jest as the test runner for all React component and TypeScript utility tests in packages/core.
- **R-JEST-002** MUST: Use React Testing Library for rendering and querying React components in tests.
- **R-JEST-003** MUST: Place all test files in `__tests__` directories co-located with source code.
- **R-JEST-004** MUST: Name test files with `.spec.tsx` or `.spec.ts` extensions.
- **R-JEST-005** MAY: Tests MAY use snapshot testing for appropriate use cases such as serialized output validation.
- **R-JEST-006** SHOULD: Use snapshots sparingly and only for stable serialized output; prefer explicit assertions for critical behavior.
- **R-JEST-007** SHOULD: Balance unit tests with integration tests that use minimal mocking.
- **R-JEST-008** SHOULD: Configure Jest with TypeScript support using ts-jest or @swc/jest for faster compilation.
- **R-JEST-009** SHOULD: Create shared test helpers and fixtures in `__helpers__` directories to promote reusability.
- **R-JEST-010** SHOULD: Configure Jest coverage thresholds in jest.config.js to maintain minimum test coverage standards.

### Verify

```bash
# Count test files using describe/it/test patterns
grep -r "describe\|it\|test" packages/core/**/__tests__/**/*.spec.tsx | wc -l

# Count __tests__ directories
find packages/core -type d -name '__tests__' | wc -l

# Verify React Testing Library usage
grep -r "@testing-library/react" packages/core/**/__tests__/**/*.spec.tsx | wc -l

# Count test files with correct extension
npm test -- --listTests | grep -E '\.spec\.(tsx|ts)$' | wc -l

# Run full test suite
npm test

# Check coverage thresholds
npm test -- --coverage
```

**Accept when:**
- All test files use `.spec.tsx` or `.spec.ts` extensions and are located in `__tests__` directories
- Jest is configured as the test runner and all tests execute successfully with `npm test`
- React component tests import and use `@testing-library/react` for rendering and queries
- Test coverage reports are generated successfully and meet minimum threshold requirements
- No test files use deprecated patterns (e.g., enzyme)
- Snapshot tests are used only for stable serialized output with explicit assertions for critical behavior
